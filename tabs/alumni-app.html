🚀 Serverless-First Architecture

Effectiveness at Scale: Engineered to support less than 5,000 active users
⚡ Next.js App Router

React Server Components for zero-bundle-size data fetching. Logic executes on the edge.

Serverless Postgres with connection pooling via Prisma to handle high-concurrency bursts.

☁️ AWS S3

Secure object storage for alumni profiles and assets, integrated via AWS SDK v3.

🎨 Tailwind v4

Zero-runtime CSS with modern fluid utilities for responsive design.
