About This Application

Purpose

This application is a Portfolio Website designed to demonstrate my skills as a Full Stack Web Developer. It simulates a desktop operating system interface in the browser to provide an interactive and engaging user experience.

The primary goal of this application is to showcase my projects, technical capabilities, and professional background to potential employers and clients.

Features

  • Desktop Simulation: A fully functional desktop environment built with HTML, CSS, and TypeScript.
  • Window Management: Draggable, extensive, and minimized windows.
  • File Explorer: A simulated file system to browse project files and documents.
  • Interactive Apps: Various "apps" that showcase different projects and skills.

Data & Privacy

This application uses Google APIs solely for the purpose of authentication and/or accessing specific portfolio-related content (such as documents or media stored in Google Drive, if applicable). We do not store your personal data.

For more detailed information, please refer to our Privacy Policy.
